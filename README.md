# Dashboard de ventas

Dashboard interactivo desarrollado con React y TypeScript para visualizar un resumen sencillo de ventas. Los datos incluidos son de demostración.

## Tecnologías
- React
- TypeScript
- Vite
- CSS

## Instalación
```bash
npm install
npm run dev
```

## Compilación
```bash
npm run build
```

## Funcionalidades
- Indicadores de ventas, pedidos y clientes.
- Gráfico de ventas por mes.
- Filtro por categoría.
- Tabla de ventas recientes.
- Diseño adaptable a celulares y computadoras.

## Publicación
El proyecto está preparado para publicarse en GitHub Pages mediante GitHub Actions.
